# ssot/norms — 生成側へ還流する規約の棚（ドメイン別に1ファイル）

**成果物への直しを、検出器ではなく生成側へ戻すための棚。** 検出器（出来たものを検査する工程）に戻すと同じ失敗を見つけるのが速くなるだけで、生成側（初稿を書く工程）に戻すと最初から起きなくなる。前者は線形、後者が複利。**なぜそうなるか・どう回すかは [`../../docs/norms-loop.md`](../../docs/norms-loop.md)**——この README は棚の書式だけを書く。

## 棚の使い方

- **1ドメイン1ファイル**（`writing.md` `proposal.md` `research.md` …）。ドメインを足すときはファイルを1本足すだけで、下の凡例は書き直さない
- **ファイル名はあなたの仕事の切り方で決める**。「文章」「提案」「調査」は例であって、配られた分類ではない
- **道具（スキル・プロンプト・テンプレート）はここを参照するだけ**。正本はこの棚に置く——道具の中に入れると、他のドメインの作り手からその規約が見えなくなる

## 凡例（全ドメイン共通の器）

棚に載る1行を**エントリ**、各エントリに付ける熟成度の札を**段**と呼ぶ。**棚には4段すべてのエントリが載る**——段が決めているのは「棚に置くか」ではなく「**初稿の指示文に入れるか**」。

| 段 | 上がる条件（目安・あなたの頻度で決める） | 使われ方 |
|---|---|---|
| **観測 n=1** | 出典1件——1つの成果物で確定した直しを一般形にしたもの | 棚に載るだけ。指示文には入れない |
| **候補** | 出典3件——別の成果物でも同じ型の直しがまた確定した | 棚に載るだけ。指示文には入れない |
| **規約** | 出典8件——同上 | **ここから上だけが、初稿の指示文に入る** |
| **常設** | 指示文に入れたあと、別の題材でも1巡目に出てこなくなった | 常時入る |

- **1行1エントリ ＋ 対応する検査軸 ＋ 出典（どの成果物のどの直しか）**。出典の無い行は、後から誰も検算できない
- **件数は出典の数そのもの。** 同じ型の直しがまた確定したら、その成果物名を出典欄に足す——それが段を上げる根拠になる。別の集計表は持たない。下の3段が数えているのは**再発**であって「防げた回数」ではない（上がるまで指示文に入っていない＝生成側は読んでいないので、防止は観測できない）
- **上の2段を差し込むのは、あなたが初稿を頼むときの指示文のひな型**（プロンプトのテンプレート・エージェントの指示ファイル・依頼メモ）。仕組みで自動化しても、毎回手で貼ってもよい——決まっているのは差し込む前の**選別**のほう
- **計器**: 成果物ごとの「1巡目の確定指摘数」を各ファイルの実測表に1行ずつ。**下がれば還流が効いている・下がらなければ検出器にしか戻っていない**
- **ガード**: エントリが増えてどの成果物も同じ顔になったら負債。週次で剪定し、最後の検出器はループの外（本人の実読・別系統のモデル・市場）に置く

## この棚は空で出荷される

**このリポジトリに入っているのは、この README と `writing.md.example`（空の骨格）だけ。エントリは1行も入っていない。**
他人の現場で焼けた規約はあなたの現場では正確に間違っていることがあり、借り物の規約は自分で焼いた規約と同じ枠を食う。最初の1行は、あなたが自分の却下から取り出したものであるべきだ。

- **この README と `.example` の2つだけはキット側のファイル**で、`git pull` で更新される。**書き足す先はドメインのファイル（`writing.md` など）で、この2つではない**——ここを編集するとリポジトリの変更として出てきて、次の `git pull` で衝突する
- **あなたのエントリはコミットできない。** `.gitignore` は許可リスト方式で、`ssot/` 配下で追跡されるのはこの README と `.example` の**2ファイルだけ**。`ssot/norms/writing.md` も、あなたが足した `ssot/norms/*.md` も、構造的に git の対象外——`git check-ignore ssot/norms/writing.md` で確かめられる
- **別ディレクトリへ scaffold した場合**（`./scripts/setup.sh ~/work-loop`）、この棚は付いていかない。`setup.sh` が配るのは `manifests/scaffold.tsv` に載っている行だけで、この2ファイルはそこに載っていない。要るならクローンから自分でコピーする
- **`.example` はわざと `.md` で終わっていない。** 棚を `*.md` で拾う仕組みが、配られた見本を「あなたの規約」として読み込むことが起こり得ないため。使うときは自分でコピーする——`cp writing.md.example writing.md`——その**コピーする動作が、あなたが選んだ地点**になる
