# 原則 (20) 承認者に残る領域

| field | value |
|---|---|
| `stable_id` | `20`（この実インスタンスの価値判断モデルの安定 ID。キット同梱の `P1, P2, …` とは別体系） |
| `publication_class` | **P0** |
| `scope` | AI へ委譲する範囲を決めるときの境界。委譲の可否であって、能力の優劣ではない。 |
| `version` | 1 |
| `adopted_at` | 2026-07-26（価値判断モデル v2 の全コーパス監査で確定した日。v1 継承分の初出日は記録が無い） |
| `status` | active |
| `verification` | ✔（一度は実発話で確認） |

**これは信条ではなく、一定条件下の運用規則だ。** 下の `scope` の外では、この原則は検証されていない——持ち帰るなら、自分の条件と突き合わせてから。

---

## 原則

承認者にだけ残るのは4つ——**①新概念の創出**（訓練データに前例がないもの）**②外向き送信の最終トリガー****③金額と温度の確定 ④命名の最終 taste**。

それ以外は委譲してよい。**戦術的な命名まで抱え込むのは委譲不足**として明示的に否定されている。
