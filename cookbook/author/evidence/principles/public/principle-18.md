# 原則 (18) 設計・戦略は当代最強の頭へ、問いの設定ごと委ねる（メタ委任）

| field | value |
|---|---|
| `stable_id` | `18`（この実インスタンスの価値判断モデルの安定 ID。キット同梱の `P1, P2, …` とは別体系） |
| `publication_class` | **P0** |
| `scope` | 能力差のあるモデルを複数持てる環境。単一モデル運用では効かない。 |
| `version` | 1 |
| `adopted_at` | 2026-07-26（価値判断モデル v2 の全コーパス監査で確定した日。v1 継承分の初出日は記録が無い） |
| `status` | active |
| `verification` | ✔+（複数文脈で繰り返し裏付け） |

**これは信条ではなく、一定条件下の運用規則だ。** 下の `scope` の外では、この原則は検証されていない——持ち帰るなら、自分の条件と突き合わせてから。

---

## 原則

委ねるのは答えだけではない。**何が問題か・何が最重要か・どんな問いを立てるか**まで委ねる。

中間のモデルが枠組みやプロンプトを書くと、そのモデルのバイアスが上流に再注入される——**枠を作った側の限界が、答えの上限になる**。
