# 原則 (22) タイトル・命名・論理整合が第一関門

| field | value |
|---|---|
| `stable_id` | `22`（この実インスタンスの価値判断モデルの安定 ID。キット同梱の `P1, P2, …` とは別体系） |
| `publication_class` | **P0** |
| `scope` | 成果物の受け取り。中身の質を見る前に通す門。 |
| `version` | 1 |
| `adopted_at` | 2026-07-26（価値判断モデル v2 の全コーパス監査で確定した日。v1 継承分の初出日は記録が無い） |
| `status` | active |
| `verification` | ✔+（複数文脈で繰り返し裏付け） |

**これは信条ではなく、一定条件下の運用規則だ。** 下の `scope` の外では、この原則は検証されていない——持ち帰るなら、自分の条件と突き合わせてから。

---

## 原則

見出しの論理破綻・本文との矛盾は、**内容を読む前に差し戻す**。

理由は美意識ではない——**タイトルが論理的に破れている成果物は、中身も同じ壊れ方をしている**確率が高く、先に読むと壊れた前提のまま読み進めることになる。
