# 原則 (30) リスク案件の選別

| field | value |
|---|---|
| `stable_id` | `30`（この実インスタンスの価値判断モデルの安定 ID。キット同梱の `P1, P2, …` とは別体系） |
| `publication_class` | **P0** |
| `scope` | 受託の引き受け判断。反応先は特定の相手ではなく案件の一般カテゴリ。 |
| `version` | 1 |
| `adopted_at` | 2026-07-26（価値判断モデル v2 の全コーパス監査で確定した日。v1 継承分の初出日は記録が無い） |
| `status` | active |
| `verification` | ✔（一度は実発話で確認） |

**これは信条ではなく、一定条件下の運用規則だ。** 下の `scope` の外では、この原則は検証されていない——持ち帰るなら、自分の条件と突き合わせてから。

---

## 原則

**手に負える構造・撤退可能な形**の仕事だけ受ける。うまくいけば儲かるが、外したときの底が見えない案件は取らない。

この原則が発火するのは見積の前だ。値付けで吸収しようとした時点で、たいてい手遅れになる。

> 発話は逐語で残してある。角括弧 `[...]` の中だけが置換で、置換の一覧は [`../../disclosure-policy.md`](../../disclosure-policy.md) §6 にある。
