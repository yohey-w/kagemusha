# 原則 (28) 正本は最小・導出可能物は持たない

| field | value |
|---|---|
| `stable_id` | `28`（この実インスタンスの価値判断モデルの安定 ID。キット同梱の `P1, P2, …` とは別体系） |
| `publication_class` | **P0** |
| `scope` | 成果物の構成設計。監査上の理由で重複が必要な領域（証憑）には適用しない。 |
| `version` | 1 |
| `adopted_at` | 2026-07-26（価値判断モデル v2 の全コーパス監査で確定した日。v1 継承分の初出日は記録が無い） |
| `status` | active |
| `verification` | ✔（一度は実発話で確認） |

**これは信条ではなく、一定条件下の運用規則だ。** 下の `scope` の外では、この原則は検証されていない——持ち帰るなら、自分の条件と突き合わせてから。

---

## 原則

**ある成果物から自動的に導出できる成果物は、持たない。** 重複した正本は乖離の温床になる。

「LLM フレンドリーな成果物のラインナップ」とは、**機械が導出できるものを人が手で保守しない**構成のことだ。
