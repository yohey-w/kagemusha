# tasks — 誰が・何を・いつまでに（と、そのタスクがどこから来たか）

> **正本 (SSOT)。** 締切のある約束はここに1箇所だけ書く。
> **出典（どこから来たか）を必ず1列。** 辿れないタスクは後で「言った/言ってない」を生む。
> 朝の棚卸し（morning_brief.sh）は、この表から締切レーダーを作る。
> **この表を維持するのはエージェント。** 人間が受信箱を検索して思い出す運用になったら、この表は死んでいる（→ [`docs/operations.md`](../../../../docs/operations.md)）。

書式のルール:
- `担当` は**いまボールを持っている側**を書く——相手が持っているなら相手の名前。
- **対外文書に「送ります」と書いたら、その瞬間に1行足す**（送信ボタンより前・承認キューに載せるより前）。
- `期日` は `YYYY-MM-DD` 固定（曜日は書かない＝機械が検算する。docs 参照）。
- `状態` は `未着手 / 進行中 / 待ち / 完了` のいずれか。完了は消さず残す（履歴）。
- `出典` は決定 ID（`D-...`）・議事録・メッセージへのリンク。
