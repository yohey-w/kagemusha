# correction_patterns.example.txt — the FORMAT, and nothing else.
#
# THIS FILE CONTAINS ZERO PATTERNS, and that is the whole point. It used to ship
# a menu of phrases to cut down; a menu is still a default for anyone who does
# not cut it down, and then their material file fills up with arguments they
# never had. The vocabulary of your corrections is the one part of this kit that
# cannot be shipped, so core ships the shape of the file and you write the lines.
#
# scripts/setup.sh creates judgment/correction_patterns.txt with comments only.
# scripts/correction_scan.py has no built-in list, requires --patterns, and
# refuses to run on an empty one — the refusal is the forcing function, not a bug
# (an empty list harvests nothing and looks exactly like a quiet week).
#
# ─── FORMAT ────────────────────────────────────────────────────────────────
# One Python regex per line, matched case-insensitively against YOUR side of the
# transcript. Blank lines and lines whose first character is '#' are ignored.
# Alternation on one line is fine and is the usual shape: several spellings of
# the same tell belong together, so one correction does not count as two.
#
# ─── HOW TO WRITE YOURS ────────────────────────────────────────────────────
# Read a week — better, a month — of your own transcripts and look for what you
# type when the agent has gone the wrong way. It is shorter and blunter than you
# expect, and it repeats: three or four phrases usually cover most of it. Those
# lines are the highest-yield patterns you will ever have here, and nobody else
# can write them for you.
#
# Aim at VOCABULARY, not meaning. "The user disagreed" is not a regex; the exact
# five words you actually type are. Include every language you work in — a
# pattern set in one language silently harvests half your corrections.
#
# ─── TUNING, in one rule ───────────────────────────────────────────────────
# Start broad, narrow later. A pattern that is too broad costs you one line to
# skim in a review. A pattern that is too narrow costs you the signal entirely,
# silently, and you will never know what you missed. The review step downstream
# throws out false hits by design — over-collection is cheap here, and
# under-collection is not.
