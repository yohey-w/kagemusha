# 会議ボード（Meet の字幕を読む）

## 何をするか

- Google Meet の**字幕**（話者の名前つき）をブラウザ拡張が読み、この PC の中のヘルパー（`127.0.0.1`）に渡します。音声は扱いません。
- ヘルパーが約 1 分ごとに、この PC の Claude Code（`claude -p`）へ整理を頼み、**別窓のボード**に「ここまでの話」を出します。話題ごとの「誰が何を言ったか」・決まったこと・持ち帰り（誰が・何を・いつ）・数字・まだ答えの出ていない問い。
- 会議の前に**事前メモ**を貼っておくと、「聞くことの表」（済／まだ）と、いま手元にあると助かるカード（最大 3 枚）も出ます。

## 要るもの

- Chrome か Edge
- Claude Code（ターミナルで `claude` と打って動くこと）
- Node.js 18 以上。入れられない PC では、https://nodejs.org/ja/download の「Windows Binary (.zip)」を展開したフォルダを `node` という名前で `start.cmd` の隣に置けば動きます（インストールも管理者権限も不要）

## 手順

1. `https://github.com/yohey-w/kagemusha/archive/refs/heads/main.zip` を落として展開し、`templates/skills/meeting-board/` を開く
2. `chrome://extensions`（Edge は `edge://extensions`）を開き、「デベロッパーモード」（Edge は「開発者モード」）をオンにして、「パッケージ化されていない拡張機能を読み込む」（Edge は「展開して読み込み」）から `extension` フォルダを選ぶ
3. `start.cmd` をダブルクリック（mac / linux は `./start.sh`）。黒い画面が開き、ボードがブラウザに出る。**この黒い画面は会議の間ずっと開いたまま**（閉じると止まる）
4. Meet に入り、字幕をオン（`C` キー）にして、字幕の言語を日本語にする。字幕がオフのままなら、拡張機能が 1 度だけオンにしてみます

ボードのタブはドラッグして別ウィンドウにし、Meet の横に置くと使いやすいです。ボードが自動で開かないときは、黒い画面に出ている `http://127.0.0.1:47431/` をブラウザに貼ります。

## 事前メモの使い方

ボードの「事前メモ」ボタンで貼ります（Markdown でも箇条書きでも可）。「前回の決定」「今日聞くこと」「資料の数字」のように書いておくと、会議の中で答えが出た項目は「済」になり、前に決めたことと違う話が出たときや、メモの数字・約束の話になったときに、カードが出ます。メモに書いていないことは出ません。起動時に `--notes メモのファイル` で読み込むこともできます。書き方の例は `sample/sample_notes.md`。

## データの扱い

- 字幕は、拡張機能からこの PC の `127.0.0.1` にだけ渡ります。このツール自身は、それ以外へ何も送りません。
- 整理のため、字幕と事前メモを**この PC の Claude Code** に渡します。Claude Code を使うときと同じく、内容は Claude のサービスで処理されます。会議の内容を入れてよいかは、会社の規則で先に確かめてください。
- 保存先は `data/<開始日時>/`（`transcript.jsonl`＝字幕、`board.json`＝ボード、`notes.md`＝事前メモ）。`data/` の中身は git に入らない設定です。要らなくなったら、そのフォルダを消してください。展開した場所が OneDrive などの同期フォルダだと、保存された字幕も同期されます。避けたいときは `--data-dir` で同期されない場所を指定します。
- 古い版の `claude`（`--no-session-persistence` を知らない版）では、整理の依頼が Claude Code 自身の履歴にも残ります。

## 会議なしで試す

```
start.cmd --replay sample\sample_transcript.txt --notes sample\sample_notes.md
```

（`meeting-board` フォルダをエクスプローラーで開き、アドレス欄に `cmd` と打って Enter を押すと、そこでコマンドプロンプトが開きます。）
架空の会議（2 人・約 60 行）を字幕として流し、ボードを動かして見せます（mac / linux は `./start.sh --replay sample/sample_transcript.txt --notes sample/sample_notes.md`）。結果の JSON だけが欲しいときは、`--once` を足すと 1 回だけ整理して出力して終わります。

## うまく動かないとき

1. ボードの**いちばん上の帯**を見ます。
   - 「字幕 ● 受信中」… 字幕は届いています
   - 「× 字幕が見つからない」… Meet で字幕をオン（`C` キー）、言語は日本語に
   - 「× 拡張機能から何も届いていません」… Meet のタブを開き直す。`chrome://extensions` で拡張機能がオンか確かめる
   - 「× ヘルパーに届きません」… `start.cmd` の黒い画面が閉じていないか
   - 赤い帯… claude のエラー（ログイン切れ・利用上限など）。文面のとおりに対処すると、次の整理から直ります
2. 拡張機能のアイコンの札は、`OFF`＝ヘルパーにつながらない、`CC`＝通話中なのに字幕が見つからない、空＝正常。
3. 「デベロッパーモード」が灰色で押せないときは、会社の設定で止められています。
4. それでも直らなければ、ボードの「**診断をコピー**」の中身を作者に送ってください。会議の発言・名前・会議コードは入っていません（画面の構造と動作の記録だけです）。

試験は Node だけで動きます（このフォルダで）: `node tests/run.js`
