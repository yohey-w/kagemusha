# 会議ボード（Meet の字幕を読む）

## 何をするか

- Google Meet の**字幕**（話者の名前つき）をブラウザ拡張が読み、この PC の中のヘルパー（`127.0.0.1`）に渡します。音声は扱いません。
- ヘルパーが約 1 分ごとに、この PC の Claude Code（`claude -p`）へ整理を頼み、**別窓のボード**に出します。
- 会議中の画面は、話しながら横目で読める 4 つだけです。
  1. **次の一手**（青・1 行・大きい字）… 次に言うこと・聞くことを 1 つ
  2. **警告**（赤）… 話がずれた・事前メモの前提と違うことを言われた・言い忘れそう、のときだけ。相手の発言の要点と、返す一言つき
  3. **順調**（緑）… 警告が無いときの進み具合 1 行
  4. **伝え済み／まだ** … 事前メモの「今日聞くこと・伝えること」の一覧（済／持ち帰り（誰）／まだ）。右上に「あと○つ」
- 「会議の前と後」のタブには、決まったこと・宿題（誰・いつまで）・まだ答えをもらっていないこと・前提と食い違ったこと・話題ごとの記録（誰が何を言ったか）が出ます。会議のあとは、そのまま**議事録の素**（Markdown）に書き出せます。

## 先に確かめること

- 字幕と事前メモは、整理のために**この PC の Claude Code**（Claude のサービス）へ渡ります。会議の内容を入れてよいか、会社の規則を先に確かめてください。
- 会社の設定で、ブラウザの拡張機能の読み込み（デベロッパーモード）が止められていないか。止められていたら、この道具は使えません。

## 要るもの

- Chrome か Edge
- Claude Code（Windows ではコマンドプロンプトで `claude` と打って動くこと。WSL の中でだけ動く場合は使えません）
- Node.js 18 以上。入れられない PC では、https://nodejs.org/ja/download の「Windows Binary (.zip)」を展開したフォルダを `node` という名前で `start.cmd` の隣に置けば動きます（インストールも管理者権限も不要）

## 手順

1. `https://github.com/yohey-w/kagemusha/archive/refs/heads/main.zip` を落として展開し、`templates/skills/meeting-board/` を開く（影武者を git で入れてあるなら `git pull` で更新するだけ）
2. `chrome://extensions`（Edge は `edge://extensions`）を開き、「デベロッパーモード」（Edge は「開発者モード」）をオンにして、「パッケージ化されていない拡張機能を読み込む」（Edge は「展開して読み込み」）から `extension` フォルダを選ぶ
3. `start.cmd` をダブルクリック（mac / linux は `./start.sh`）。黒い画面が開き、ボードがブラウザに出る。**この黒い画面は会議の間ずっと開いたまま**（閉じると止まる）
4. Meet に入り、字幕をオン（`C` キー）にして、字幕の言語を日本語にする。字幕がオフのままなら、拡張機能が 1 度だけオンにしてみます
5. 会議が終わったら黒い画面を閉じる（または Ctrl+C）。次の会議は `start.cmd` をもう一度（字幕は起動ごとに別のフォルダに保存されます）。止めずに続けて使うときは、ボードの「新しい会議」を押す

初めて使う日は、会議の前に一度「会議なしで試す」（下）を回して、ボードに整理が出ることを確かめておくと安心です。

ボードのタブはドラッグして別ウィンドウにし、Meet の横に置くと使いやすいです。ボードが自動で開かないときは、黒い画面に出ている `http://127.0.0.1:47431/` をブラウザに貼ります。

## 事前メモの使い方

会議の前に、ボードの「事前メモ」ボタンで貼ります（起動時に `--notes メモのファイル` で読み込むこともできます）。見出しをこのように付けると、ボードが項目の文言と順番をそのまま使います。書き方の例は `sample/sample_notes.md`。

```
自分：山田                ← 字幕に出る自分の名前（自分の発言を言い直して返さないため）

## 前回の決定
- 切り替えは来年の4月1日に行う。

## こちらの理解            ← 相手に違うと言われたら、赤い警告で知らせる
- 解約の連絡は1か月前で足りる。

## 今日伝えること
- 予算の上限は年額150万円であること。

## 今日聞くこと            ← 番号の順が「聞くつもりの順」。次の一手はこの順で選ぶ
1. 新システムの月額（1人あたり）はいくらか。
2. 現行システムの契約はいつ終わり、解約の連絡はいつまでに必要か。

## 手元の資料の数字
- 現行システム: 年額 96万円
```

- 「今日聞くこと・伝えること」の項目は、会議の中で「済」「持ち帰り（誰）」「まだ」になります。次の一手は、まだの項目から事前メモの順に選びます（Claude が出さなかったときも、まだの最初の項目を出します）。
- 状態が違っていたら、自分で直せます。会議中は「伝え済み／まだ」の項目を押すと まだ → 済 → 持ち帰り の順に変わり、「会議の前と後」タブでは［済］［持ち帰り］［まだ］で選べます。手で直した状態は、そのあとの整理より優先します（「整理に任せる」で戻せます）。
- 見出しは「確認事項」「質問」「前提」「決定事項」などでも読みます。読めたかどうかは、「会議の前と後」タブの「事前メモから読んだこと」で確かめられます。
- メモに書いていない前提で警告は出ません。

## 画面の使い方（会議の前・中・後）

- **会議の前**: 事前メモを貼り、「会議の前と後」タブの「事前メモから読んだこと」で、聞くこと・伝えること・こちらの理解が並んでいるか見ます。
- **会議中**: 「会議中」タブ（既定）。普段は「次の一手」だけ見れば足ります。赤い帯が出たら、返す一言を見ます。画面の場所は更新で動きません。整理の最中は右上に「整理中…」、いちばん下に最終更新の時刻が出ます。整理が止まったり遅れたりしているときは、内容が薄くなり「○分前の内容」と出ます（上の帯の赤い文に理由が出ます）。
- **会議の後**: 「会議の前と後」タブで振り返り、議事録の素を書き出します（下の「会議のあとに議事録の素を書き出す」）。
- 各欄の 1 行の説明は、慣れたら下の「説明を隠す」で消せます。

## 会議のあとに議事録の素を書き出す

```
.\start.cmd --minutes data\<開始日時> --out minutes.md
```

（mac / linux は `./start.sh --minutes data/<開始日時> --out minutes.md`）。決まったこと／宿題（誰・いつまで）／まだ答えをもらっていないこと／前提と食い違ったこと／聞くこと・伝えることの結果／話題ごとの記録、の順の Markdown になります。`--out` を付けなければ画面に出します。`--once` の出力（JSON）を保存したファイルからも書き出せます。**自動字幕からの下書きなので、外に出す前に必ず見直してください。** このツールはどこにも送りません。

## 整理の速さ（差分の整理）

- 1 回目は会議の全体を整理し、2 回目からは「前回より後の字幕」と「変わったところだけ」をやり取りします（差分の整理）。話者の交代が続いたときや字幕がたまったときは、間隔を待たずに前倒しで整理します。
- 差分を 8 回続けたとき・前の全体から 10 分たったとき・差分の返事がおかしかったとき・事前メモを変えたとき・再生の終わりには、全体で整理し直します。毎回全体で整理したいときは `--mode full` を付けます。
- 整理 1 回ごとの所要時間と費用（数字だけ）は、会議フォルダの `updates.jsonl` に残ります（`mode` が `full`＝全体、`diff`＝差分）。
- 付属の短い会議（58 行）で測ったところ、全体 1 回は約 27 秒・約 0.07 ドル、残り 23 行の差分 1 回は約 21 秒・約 0.06 ドルでした（2026-10-23・既定の `--model sonnet`。1 回ずつ測っただけで、ばらつきは測っていません。会議が長いほど差が出る見込みです）。

## データの扱い

- 字幕は、拡張機能からこの PC の `127.0.0.1` にだけ渡ります。このツール自身は、それ以外へ何も送りません。
- 整理のため、字幕と事前メモを**この PC の Claude Code** に渡します。Claude Code を使うときと同じく、内容は Claude のサービスで処理されます。会議の内容を入れてよいかは、会社の規則で先に確かめてください。
- 保存先は `data/<開始日時>/`（`transcript.jsonl`＝字幕、`board.json`＝ボード、`notes.md`＝事前メモ、`updates.jsonl`＝整理 1 回ごとの所要時間と費用。本文は入らない、`overrides.json`＝手で直した聞くことの状態）。`data/` の中身は git に入らない設定です。要らなくなったら、そのフォルダを消してください。展開した場所が OneDrive などの同期フォルダだと、保存された字幕も同期されます。避けたいときは `--data-dir` で同期されない場所を指定します（例: `.\start.cmd --data-dir C:\meeting-board-data`）。
- 古い版の `claude`（`--no-session-persistence` を知らない版）では、整理の依頼が Claude Code 自身の履歴にも残ります。

## 会議なしで試す

```
.\start.cmd --replay sample\sample_transcript.txt --notes sample\sample_notes.md
```

（`meeting-board` フォルダをエクスプローラーで開き、アドレス欄に `cmd` と打って Enter を押すと、そこでコマンドプロンプトが開きます。先頭の `.\` は、Git Bash や PowerShell のように「今のフォルダを探さない」画面でも同じ命令で動かすためのものです。）
架空の会議（2 人・約 60 行）を字幕として流し、ボードを動かして見せます（mac / linux は `./start.sh --replay sample/sample_transcript.txt --notes sample/sample_notes.md`）。

- 流す速さは、既定で「整理が 6 回ほど入る速さ」に自動で決まります（付属の会議は約 6 分半）。起動時に「○倍速で流します（約○分・整理はおよそ○回の見込み）」と出ます。速さを決めたいときは `--speed 2` のように付けます（1 倍は 1 行あたり約 4 秒）。
- 自分の文字起こしを流すときは、1 行を「話者：本文」の形にします。行の頭に `[10:03:15]` や `[10:03]` の時刻があれば、その間隔で流します（長い沈黙は 10 秒に縮めます）。自分の名前は `--me 山田` で指定すると、自分の発言を言い直して返さなくなります。
- 結果の JSON だけが欲しいときは、`--once` を足すと 1 回だけ整理して出力して終わります（`--mode diff` を足すと、前 6 割で全体 → 残りで差分の 2 回）。
- 会議のあとの文字起こしも流せます: WebVTT（`.vtt`。話者が `<v 名前>` か「名前: 」）と、「名前 0:01:23」の行の次に本文が続く `.txt`（Teams の文字起こしを Word で .txt に保存した形）。**どちらも広く知られた形からの推定で、実物の Teams・Zoom のファイルでは確かめていません。** 読めた形と件数が最初に出ます。形を見分けられないときは、そう言って止まります（でたらめな行は作りません）。

### 整理の質を測る（手で回す）

```
node helper/server.js --replay sample/sample_transcript.txt --notes sample/sample_notes.md --once > out.json
node tests/eval/score_board.js out.json
```

付属の架空の会議に合わせた物差しです（話題の数・あいさつの話題が無いか・自分の発言の言い直しの割合・次の一手・聞くことの状態・仕込んだ前提の食い違いを拾えたか）。これは本物の claude を 1 回呼びます。`node tests/run.js` には入っていません。

## うまく動かないとき

1. ボードの**いちばん上の帯**を見ます。
   - 「字幕 ● 受信中」… 字幕は届いています
   - 「× 字幕が見つからない」… Meet で字幕をオン（`C` キー）、言語は日本語に
   - 「× 拡張機能から何も届いていません」… Meet のタブを開き直す。`chrome://extensions` で拡張機能がオンか確かめる
   - 「× ヘルパーに届きません」… `start.cmd` の黒い画面が閉じていないか
   - 赤い帯… claude のエラー（ログイン切れ・利用上限など）。文面のとおりに対処すると、次の整理から直ります。同じ文は黒い画面にも出ます（会議の発言・名前は伏せてあります）
   - 内容が薄く「○分前の内容」… 整理が止まっているか遅れています。赤い帯の文を見てください。待つと、次の整理で自動でやり直します
2. 拡張機能のアイコンの札は、`OFF`＝ヘルパーにつながらない、`CC`＝通話中なのに字幕が見つからない、空＝正常。
3. 「デベロッパーモード」が灰色で押せないときは、会社の設定で止められています。
4. それでも直らなければ、ボードの「**診断をコピー**」の中身を、直す人に渡してください。会議の発言・名前・会議コードは入っていません（画面の構造と動作の記録、整理の所要時間と費用の数字だけです）。
5. 0.1 から入れ替えたときは、`chrome://extensions` で拡張機能の「再読み込み」（↻）を押してください（字幕の途中経過が 1 行につながって保存される不具合は、拡張機能の側で直しています）。

試験は Node だけで動きます（このフォルダで）: `node tests/run.js`
