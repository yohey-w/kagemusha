# 前回の決定事項（デモ・架空）

会議前に運用側がここへ書き出しておくと、会議中に画面上部の「資料棚」からボタン1つで開ける。
共有窓（`/stage/*`）には出ない — **手元だけの棚**。

| 決めたこと | 誰が | いつまで |
|---|---|---|
| 移行対象は本番データのみ | 双方 | 決定済み |
| たたき台をこちらが用意する | 進行役 | 次回まで |
| 検証環境の扱いは次回に持ち越し | 双方 | 次回 |

## 補足

- 「全部移したい」と言われたら、まず本番だけで動かして次の弾で広げる、という順番で返す。
- 金額・期限・責任の話が出たら、その場で決めずに持ち帰る（番人が赤いカードで止める）。
