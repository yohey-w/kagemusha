meetlive 子機 — ノートPC用の手順（5分）
=======================================

これは何か
----------
会議の音をノートPCで拾って、親機（受信サーバが動いている機体）へ送るだけの小さな道具です。
文字起こしと答えカードは親機側でやります。ノートPCは音を送るだけ。

答えカードは「スマホ」で見ます。PCに出すと画面共有に映り込むためです。


はじめに1回だけ（2〜3分）
-------------------------
1. この一式を、ノートPCの好きな場所に展開する
   （デスクトップでよい。日本語やスペースを含むフォルダ名は避ける）

2. 親機とつながるプライベート網（tailscale 等）がノートPCに入っているか確認する
   ※これが無いと親機に届きません。LAN内で完結するなら不要です

3. setup.cmd をダブルクリック
   Python と音を録る部品が自動で入り、config.txt が作られてメモ帳が開きます。

4. config.txt を書き換える
     host  = 親機のアドレス
     port  = 親機の receiver.py が待っているポート（既定 47311）
     token = 親機と合わせる合言葉
   ※ token は他人に渡さないこと。config.txt は git に入れないこと。


会議のたび（30秒）
------------------
1. イヤホン／イヤモニを挿す  ← 必ず START.bat より先に
   スピーカーで相手の声を鳴らすと、自分のマイク（ch T）が相手の声（ch G）を
   拾い直して二重に数えられ、話者の分離が壊れます。段の進行判定も前提監視も、
   「誰が言ったか」を土台にしているので、ここが壊れると全部が狂います。

2. START.bat をダブルクリック
   窓が2つ開きます。
     MIC  窓 … 自分の声   → 「接続OK -> 送信中」
     LOOP 窓 … 相手の声   → 「connected OK -> sending」
   2つとも出れば成功です。

3. スマホでカンペ画面を開く:  http://<親機のアドレス>:47323

4. 会議が始まったら「同席開始」と声に出す
   ・分からないことがあれば「<呼びかけ語>、○○って何だっけ」と呼ぶ
   ・段取りを送りたいときは「<呼びかけ語>、次」／戻したいときは「<呼びかけ語>、戻って」
   （<呼びかけ語> は親機側の MEETLIVE_CALL_WORDS で決めた語）

5. 終わったら「同席終了」と言い、2つの窓を閉じる（または STOP.bat）


うまくいかないとき
------------------
・「接続OK」の行が出ない
   → プライベート網がつながっているか確認する
   → config.txt の host / port が親機と合っているか確認する
   → 合言葉（token）が親機の設定と一致しているか確認する
     （違うと親機側が「合言葉が違う」と出して即切断します）

・相手の声だけ入らない
   → 会議アプリの音が出ているスピーカーが「既定のデバイス」か確認。
     イヤホンを挿し直したら START.bat を叩き直す。
     （音の取り込み先は起動時に決まるため）

・自分の声だけ入らない
   → Windowsの設定でマイクが「既定のデバイス」か確認。
   → 既定マイクが Bluetooth 機器だと取得時に落ちることがある。
     その場合は config.txt の mic_match に内蔵マイク名の一部を書く（例: mic_match=Realtek）。

・二重に文字が出る
   → 子機が2つ動いている。STOP.bat を叩いてから START.bat。


細かい話
--------
・送っているのは 16kHz mono ×2本＝およそ 512kbps。テザリングでも通ります。
・接続先や音質を変えたいときは config.txt を書き換える（起動時に1回だけ読む）。
・agent.py（start.cmd）は2系統を1プロセスで扱う簡易版。片方のデバイスが落ちると
  両方まとめて死ぬので、実運用は START.bat（窓を分ける）を使うこと。
